# Prometheus Metrics Skill

This repository contains the Prometheus metrics skill draft for the Grafana AI Agent work.

Files:

- `prometheus_metrics_skill.md` - the repo-facing skill reference and PromQL cookbook for the four Prometheus metric areas.
- `prometheus_metrics_SKILL.md` - the original uppercase copy used by the local test agent.

The current draft covers:

1. CPU Usage (Infra)
2. Memory Usage (Infra)
3. Process CPU Usage
4. Process Memory Usage

The intent is to keep this repo focused on the skill document itself and later updates to that prompt structure.
